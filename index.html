GOOD TO KNOW

Questions, answered.

What kind of websites can I upload?

Static HTML, CSS, JavaScript, images, fonts, and other static assets. No PHP, Node.js servers, Python apps, or databases.

Can I connect my own domain?

Custom-domain setup is not included in this early version. Published sites receive a Cloudflare Pages subdomain. A custom domain requires separate configuration and a domain you control.

Is it free?

This MVP is designed around provider free tiers, which have limits and can change. We do not promise unlimited storage, bandwidth, projects or uptime. No payments are collected in this version.

What are the upload limits?

Each ZIP can be up to 8 MiB. After extraction, a site can contain up to 100 files and 20 MiB total. The ZIP must contain index.html at its root and may not include hidden or unsafe paths.

Does Zapify Hosting include email or databases?

No. This version publishes static website files only. It does not provide mailboxes, database hosting, server-side code, WordPress hosting or backend application runtimes.

Can I upload WordPress?

Not a live WordPress installation. A static export may work if it contains ordinary static files and a root index.html.
