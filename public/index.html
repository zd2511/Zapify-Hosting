GOOD TO KNOW

Questions, answered.

What kind of websites can I upload?

Static HTML, CSS, JavaScript, images, fonts, and other static assets. No PHP, Node.js servers, Python apps, or databases.

Can I use my own domain?

Custom domains are not enabled in this starter. A future setup requires a domain you own and DNS changes. The initial publishing target is a Cloudflare Pages subdomain.

Is it really free?

The starter uses provider free tiers, which have limits and can change. Zapify cannot promise unlimited storage, bandwidth, projects, or uptime. No payments are collected in this MVP.

Can I upload WordPress?

Not a live WordPress installation. A static export may work if it contains ordinary static files and a root index.html.
